## Animation Timings

### Transitions
```
Fast:     200ms  (Hover effects)
Medium:   300ms  (Button states, color changes)
Slow:     500ms  (Card entrances, testimonial transitions)
```

### Keyframe Animations
```
Counter:     2000ms (Number count-up)
Scroll:      600-800ms (Fade-in-up)
Float:       3000ms (Continuous gentle movement)
Parallax:    Scroll-linked (Background vs foreground)
```

## Responsive Breakpoints

### Mobile (< 640px)
- Single column layouts
- Stacked buttons
- Smaller typography (5xl headlines)
- Reduced padding (py-16)
- 2-column stats grid

### Tablet (640px - 1024px)
- 2-column grids
- Horizontal buttons
- Medium typography (7xl headlines)
- Standard padding
- Some 3-column sections

### Desktop (1024px+)
- 3-6 column grids
- Full horizontal layouts
- Largest typography (8xl headlines)
- Maximum padding
- All features visible

## Accessibility Features (Visual)

### Focus States
- **Color**: Red outline (#b60807)
- **Width**: 2px
- **Offset**: 2px from element
- **Visibility**: High contrast, visible on all backgrounds

### Color Contrast Ratios
```
Black on White:       21:1 (WCAG AAA)
Gray-900 on White:    18:1 (WCAG AAA)
Gray-600 on White:    7:1  (WCAG AAA)
White on roofRed:     4.8:1 (WCAG AA)
White on Gray-900:    18:1 (WCAG AAA)
```

### Text Sizing
- Minimum body text: 16px (recommended 18px)
- Line height: 1.5-1.8 for body text
- Letter spacing: Normal to slightly wide for headings

### Touch Targets
- Minimum size: 44x44px (WCAG 2.1 AA)
- Buttons: 48px+ height
- Spacing between: 8px minimum
